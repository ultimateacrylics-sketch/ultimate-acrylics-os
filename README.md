# Ultimate Acrylics OS

Cloud-ready production starter.

## Included
- Next.js dashboard
- Sidebar navigation
- Responsive layout
- Supabase client setup
- PostgreSQL schema
- Vercel-ready configuration

## Deploy
1. Create a GitHub repository named `ultimate-acrylics-os`.
2. Upload this package.
3. Import the repository into Vercel.
4. Add the Supabase environment variables.
5. Run `supabase/schema.sql` in Supabase SQL Editor.
